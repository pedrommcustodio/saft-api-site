2. Resultado apenas informativo

Um resultado, incluindo valid: true, é informativo. Não significa que a Autoridade Tributária e Aduaneira aceite o ficheiro. Não é aconselhamento fiscal, contabilístico ou jurídico. Não é certificação de facturas, nem comunicação de séries ATCUD, nem submissão à Autoridade Tributária. Continua a ser responsável pelo ficheiro que entregar à Autoridade.

3. Sem conservação

Os ficheiros são processados em memória e eliminados quando a resposta é enviada. Veja a política de privacidade. Não envie um ficheiro se não puder partilhá-lo com um subcontratante, ou com a plataforma que usa para chamar a API.

4. Utilização

Não use a API para violar a lei, para sobrecarregar o serviço, ou para tentar ler dados de outros clientes. Não existe arquivo de ficheiros de outros clientes. Os limites e os preços são os do plano da plataforma que comprar (Zyla API Hub ou RapidAPI), e não de um checkout separado nesta origem.

5. Disponibilidade

O serviço é prestado conforme disponível. Manutenção, limites do alojamento e falhas podem interrompê-lo. Estes termos não prometem um nível de disponibilidade. As regras de nível de serviço da plataforma, se existirem, são entre si e essa plataforma.

Na medida em que a lei portuguesa o permita, não respondemos por danos indirectos ou lucros cessantes, nem por um ficheiro ser rejeitado pela Autoridade Tributária depois de a API o ter indicado como válido. Nada nestes termos exclui responsabilidade que a lei portuguesa não permita excluir, incluindo dolo. Se um tribunal considerar aplicável um tecto, o tecto num período pago é o montante que pagou por esta API através da plataforma nos três meses anteriores à reclamação. Se nada pagou, o tecto é zero para os danos que a lei permita limitar.
